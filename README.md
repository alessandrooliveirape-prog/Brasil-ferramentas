**Tool Brasil** is a comprehensive, client-side web utility suite offering essential tools for software engineers, digital creators, and everyday internet users. Designed with a clean glassmorphic UI, zero server dependencies, and maximum privacy.

---

## 🌟 Key Features & Utilities

### 1. 💻 Developer & Data Utilities
* **Synthetic Data & Validation Engines:** Algorithmic verification and test-data generation for regional identification schemas (CPF/CNPJ check-digit algorithms) for software QA testing.
* **Formatters & Beautifiers:** Instant client-side JSON formatting, minification, tree inspection, and validation.
* **Encoding & Hashing:** Safe Base64 text and image encoding/decoding, URL encoding, and cryptographic hash utilities.
* **UUID & Password Generators:** Cryptographically secure UUID v4 generation and configurable entropy password creation.

### 2. 📝 Text & Content Manipulation
* **Case Converters:** CamelCase, snake_case, kebab-case, Title Case, and UPPERCASE/lowercase transformation.
* **Text Metrics:** Live character, word, sentence, and reading-time counters.
* **Text Diff & Cleaner:** Duplicate line remover, whitespace trimmer, and string sanitization.

### 3. 🎨 CSS & Front-End Visual Generators
* **Box Shadow Studio:** Interactive multi-layer shadow builder with visual controls and CSS snippet export.
* **CSS Gradient Generator:** Multi-stop linear and radial gradient design canvas.
* **Border Radius & Flexbox Playground:** Tactile visual builders with real-time preview.

### 4. 🔒 Privacy-First Architecture
* **100% Client-Side Execution:** All calculations, formatting, and data generation happen entirely inside the user's browser using standard Web APIs. No user data, text inputs, or generated keys are ever transmitted across the network.

## 🚀 Getting Started

### Prerequisites
* **Node.js** 18+ and **npm**

### 1. Clone the Repository
```bash
git clone https://github.com/alessandrooliveirape-prog/Brasil-ferramentas.git
cd Brasil-ferramentas
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Locally
```bash
npm run dev
```
Navigate to `http://localhost:5173` to explore the utility suite.
